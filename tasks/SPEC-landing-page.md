# Landing page

Objective: an editorial marketing page promising less time reconstructing a workday.
Lead with “Finish work. Your timesheet is already started.” Show a clearly marked
example review and explain work → review → confirm. State Linux availability and
optional cloud AI honestly. Avoid implementation details as headline benefits.

Keep the marketing shell independent. Use a warm neutral/forest palette, clear
headline hierarchy, and a product-specific timeline made with HTML and CSS. No
invented customers or statistics. Verify 320/768/1440px, light/dark, CTA navigation,
keyboard, and production build. Never claim activity proves task completion.
